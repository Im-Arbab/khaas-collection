# Khaas Collections

An e-commerce website for Chikan (Chikankari) ethnic wear, with women's, men's and bridal collections.

🔗 **Live Demo:** https://khaas-collections.vercel.app/

## Features

- Product categories: Chikan kurtis, suits, sarees, anarkalis, dupattas, sherwanis and kurta-payjama
- Shop pages with product listing and product details
- Cart, checkout and wishlist
- Order tracking page
- Sign in / register page
- Blog and contact pages
- Responsive design for mobile and desktop

## Tech Stack

- React.js
- JavaScript (ES6+)
- CSS / Bootstrap / Tailwind CSS
- Deployed on Vercel

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git

# Go into the project folder
cd <your-repo-name>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Build for Production

```bash
npm run build
```
